# Numerical Methods Lab Course

This repository contains the code developed as part of the **Numerical Methods Lab** course at Ludwig-Maximilians-Universität München (LMU).

The project focuses on the implementation and application of numerical integration methods, with particular emphasis on understanding the underlying algorithms and their numerical accuracy.

## Contents

The repository includes implementations of numerical integration methods covering:

- **Equal-step methods:** Numerical integration over uniformly spaced grids.
- **Unequal-step methods:** Numerical integration over non-uniformly spaced grids.
- **Error analysis:** Evaluation of numerical accuracy, convergence, and comparison between different integration methods.
- **Astrophysical application:** Application of the developed numerical methods to the calculation and analysis of Strömgren spheres.

The implementations are developed from scratch to understand the numerical procedures rather than relying entirely on pre-existing integration routines.
